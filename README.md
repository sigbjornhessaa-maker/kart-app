# kart-app
Mitt første kart-app prosjekt: et kart over Trondheim der du kan klikke for å legge til punkter med navn,
bytte mellom gatekart, topografisk kart og satellittbilder, måle avstander og se
vedtatte reguleringsplaner (fra DiBK) med informasjon om planen du klikker på.

## Filer
- `index.html` – strukturen på siden (overskrift, kart-boks, liste).
- `style.css` – utseendet (farger, størrelser, oppsett på mobil).
- `script.js` – oppførselen (lager kartet, reagerer på klikk, lagrer punkter, henter planinfo).
- `arealformal.js` – oversetter arealformål-koder (f.eks. 2011) til tekst (Kjøreveg).

## Kjøre lokalt
Åpne `index.html` i nettleseren (dobbeltklikk på filen).

## Publisering
Appen publiseres med GitHub Pages: Settings → Pages → «Deploy from a branch» → `main` / `(root)`.
